# OneSystec — Landing page

Sitio estático (HTML + CSS + JS, sin dependencias) para onesystec.com.

- Idiomas: italiano (por defecto), español, inglés → textos en `assets/js/i18n.js`
- Configuración rápida (link de iniciar sesión, correo de contacto) → arriba de `assets/js/main.js`
- Imágenes → `assets/img/`

Para verlo en local: abre `index.html` o ejecuta `python3 -m http.server`.
Despliegue: Vercel (proyecto estático, sin build).
